## Golf-Logik nach WHS / DGV

| Wert | So wird gerechnet |
|---|---|
| Spielvorgabe | round(HI · Slope / 113 + CR − Par), 9-Loch-Plätze mit halbem Index |
| Stableford | max(0, 2 + Par + Vorgabeschläge − Schläge) |
| Score-Differential | mit Netto-Doppelbogey als Lochmaximum |
| Virtuelles Handicap | beste n der letzten 20 Runden nach WHS-Tabelle, 9-Loch-Runden mit erwartetem Ergebnis für die zweite Hälfte |

Striche zählen im Brutto als Netto-Doppelbogey (Par + 2 + Vorgabeschläge).
